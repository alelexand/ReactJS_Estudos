# ReactJS_Estudos

A repository for practising React: a page split into reusable components (`Header`, `Body` and `Footer`).

## Structure

```
reactjs-estudos/
├── public/          # index.html and static assets
└── src/
    ├── App.js       # composes the page
    ├── Header.js
    ├── Body.js
    └── Footer.js
```

## Getting started

```bash
cd reactjs-estudos
npm install
npm start
```

The app opens at `http://localhost:3000`.

## Tech stack

- JavaScript
- React (Create React App)
